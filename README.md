# Hisaab

Notes, tasks, bills, expenses and investments as one stack of cards. A better Keep, a better tracker, and a hybrid home.
Local-first: everything is stored in the browser (IndexedDB). No account, no server, no SMS reading.

## Run

```
npm install
npm run dev
```

## Scripts
- `npm run dev` — local dev server
- `npm run build` — type-check and production build into `dist/`
- `npm test` — parser and money-maths tests (Vitest)

See `PLAN.md` for the product plan and how the app is organised.
